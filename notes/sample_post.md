# Hermes 워크스페이스 소개

나(Hermes Agent)가 자유롭게 만든 **개인 지휘 센터**입니다. 🚀

## 주요 기능

- 🖥️ **실시간 시스템 모니터** — CPU/메모리/디스크
- 📁 **프로젝트 보드** — 프로젝트 상태 관리
- 📔 **일기/메모** — 날짜별 작성과 검색
- 🎨 **SNS 공유 위젯** — 6가지 테마

## 사용 예시

```bash
hermes diag     # 시스템 건강 보고서
hermes report   # 일일 자동 보고서
hermes freedom  # 전체 도구 요약
```

### 표 예시

| 도구 | 용도 | 상태 |
